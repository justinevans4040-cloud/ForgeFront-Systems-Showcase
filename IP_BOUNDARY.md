# ForgeFront Showcase IP Boundary

This repository exists for capability evaluation and collaboration discovery. It is not a source repository, deployment repository, operations repository, or implementation reference.

## Never publish here

- proprietary source code or executable logic
- system prompts, hidden instructions, prompt libraries, or protected context
- API keys, tokens, credentials, certificates, secrets, or environment files
- customer, partner, employee, or private datasets
- proprietary algorithms, formulas, weighting systems, or model logic
- internal agent identifiers that reveal protected topology or orchestration
- task-routing contracts, execution sequences, runbooks, rollback mechanics, or recovery implementation
- infrastructure topology, hostnames, private endpoints, network maps, deployment manifests, or service configuration
- security rules whose disclosure would weaken protections
- internal schemas or artifacts sufficient to reproduce protected workflows

## Appropriate showcase material

- high-level capability and outcome descriptions
- product names and approved public positioning
- sanitized screenshots and product visuals
- public links
- non-sensitive milestones
- collaboration descriptions
- diagrams that communicate value without revealing implementation

**Rule:** demonstrate the machine's power without publishing its blueprints.
