# Security & Disclosure

This repository is intentionally non-operational and is maintained as a sanitized showcase only.

It must not contain deployable ForgeFront source, prompts, credentials, private data, infrastructure details, orchestration internals, or implementation material sufficient to reproduce protected systems.

If sensitive material is discovered here, do not redistribute it. Report it directly to ForgeFront Systems so the material can be removed and any affected secret, access path, or dependency can be remediated.
