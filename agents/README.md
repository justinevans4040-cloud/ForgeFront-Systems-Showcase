## The Britt
**Windows-first local execution**  
The Britt is a real local execution system with tooling for files, PowerShell, desktop actions, scheduling, Google Drive, memory, diagnostics, and configured Ubuntu SSH operations. Runtime state, credentials, tokens, SSH state, and operator workspace material remain outside version control.

## Operating principle

The value of the ForgeFront agent stack is not the number of names on a page. It is specialization, real tool access, controlled execution, verification, continuity, and the ability to keep different kinds of work from collapsing into one undifferentiated assistant.

**Public proof stays visual and outcome-focused. Protected implementation stays private.**
