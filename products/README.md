# Products & Platforms

**ForgeFront Systems builds software around real operator workflows, where intelligence belongs inside the work instead of sitting beside it in a generic chat window.**

This portfolio is intentionally descriptive rather than reproducible. Product internals, protected logic, prompts, models, formulas, orchestration, credentials, private datasets, and deployment secrets remain outside this repository.

## Portfolio Rule

Every project in this portfolio should be described from its **current canonical source** whenever one exists. Historical experiments, recovered files, old decks, and earlier product language may provide provenance, but they do not outrank the active repository or newer verified Drive material.
