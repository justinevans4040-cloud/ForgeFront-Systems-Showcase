# ODIN LINEFORGE

**Operator-grade sports analysis and decision-support software.**

ODIN LINEFORGE is built to organize sports-analysis inputs into a clear decision surface rather than reduce the work to generic picks or chat-style output.

## Public capability view

- matchup context
- market context
- risk awareness
- confidence framing
- injury and weather context
- structured decision support

## Protected core

This showcase does not publish ODIN's models, formulas, weights, prompts, data flows, automation, deployment details, source code, or any implementation material sufficient to reproduce the system.

**The product is visible. The engine stays private.**
